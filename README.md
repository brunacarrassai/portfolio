# Portfólio — Bruna Carrassai

React + Vite. Tema escuro/claro, animações ao rolar, 100% responsivo.

## Rodar
```
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist/ (pronta para GitHub Pages, Netlify, Vercel)
```

## Onde editar
- `src/data.js` — textos, links, habilidades e projetos
- `src/styles.css` — cores (variáveis no topo), fontes e layout
- `public/curriculum.pdf` — seu CV
- `src/assets/` — imagens
